# Política de seguridad

## Versiones compatibles

La rama predeterminada recibe correcciones de seguridad. No se garantiza mantenimiento para copias antiguas o forks.

## Reportar una vulnerabilidad

No publiques credenciales, datos personales, rutas privadas ni detalles explotables en un issue público.

Usa la opción **Report a vulnerability** de GitHub Security Advisories en este repositorio. Incluye:

- componente y versión afectados;
- pasos mínimos para reproducir;
- impacto esperado;
- propuesta de mitigación, si existe.

Se acusará recibo cuando el propietario revise el reporte. Los tiempos de solución dependen de la gravedad y de la reproducibilidad.

## Alcance

AussieCare no tiene cuentas, pagos, base de datos ni API propia. Los principales límites de confianza son el Service Worker, la persistencia local, la cadena de dependencias y los archivos estáticos servidos por el host.
